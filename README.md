# Porsche Sales Intelligence Dashboard

Dashboard executiva de inteligência comercial para análise de vendas de veículos Porsche.

O projeto transforma uma base de vendas em uma experiência analítica interativa, permitindo explorar desempenho comercial por **modelo, Model Year, cidade e método de pagamento**, além de identificar tendências e padrões de vendas ao longo do tempo.

## Visão geral

A dashboard foi desenvolvida com foco em:

- Análise rápida para tomada de decisão;
- Visualização elegante e minimalista;
- Exploração dos dados por filtros;
- Identificação de modelos mais populares;
- Comparação do desempenho entre cidades;
- Análise da evolução mensal das vendas;
- Geração de insights comerciais a partir do recorte selecionado.

A linguagem visual foi inspirada no posicionamento premium da Porsche Brasil, priorizando uma interface limpa, sofisticada e com forte hierarquia visual.

## Funcionalidades

### Filtros

A dashboard permite segmentar os dados por:

- **Modelo da Porsche**
- **Model Year**
- **City**
- **Pay Method**

Os indicadores e gráficos são atualizados de acordo com o recorte selecionado.

### KPIs

O painel apresenta:

| KPI | Descrição |
| --- | --- |
| **Vendas** | Quantidade de veículos vendidos no recorte |
| **Receita** | Soma do valor das vendas |
| **Ticket médio** | Receita média por veículo |
| **Model Year líder** | Ano de modelo com maior volume de vendas |

### Análises

#### Evolução das vendas

Gráfico temporal que mostra o volume de vendas mês a mês, permitindo identificar:

- Crescimento ou queda de demanda;
- Períodos de maior volume;
- Sazonalidade;
- Mudanças no ritmo comercial.

#### Principais modelos por cidade

Ranking visual das cidades com maior volume de vendas, permitindo entender quais modelos possuem maior presença em cada mercado.

#### Modelos mais vendidos

Ranking dos modelos Porsche com maior quantidade de vendas dentro dos filtros selecionados.

#### Model Year mais vendido

Distribuição das vendas por ano de modelo, destacando o Model Year com maior volume.

#### Insights comerciais

A dashboard gera insights dinamicamente a partir dos dados filtrados, incluindo:

- Cidade em destaque;
- Modelo mais popular;
- Model Year dominante;
- Método de pagamento mais utilizado.

#### Detalhamento

Tabela com as vendas mais recentes do recorte, contendo:

- Data;
- Modelo;
- Model Year;
- Cidade;
- Método de pagamento;
- Valor da venda.
